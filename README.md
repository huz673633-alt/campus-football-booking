# 校园足球场预约系统

这是一个面向校园足球场景的中文预约系统原型。示例包含三块足球场，每块场地划分为 A、B 两个半场，让学生按小时预约，同时允许学校管理员提前发布活动、施工和维护封场安排。

## 当前版本能做什么

- 查看未来 7 天三块足球场及其左右半场的可用时间
- 预约指定球场的一个半场，并阻止同一时段重复预约
- 查看或取消当前浏览器创建的预约
- 管理员按日期、时间、球场和半场范围发布封场安排
- 自动标记因封场受到影响的预约
- 同一浏览器的不同标签页之间自动刷新状态
- 支持手机和电脑屏幕

## 重要说明

当前是第一阶段的本地演示版，数据保存在浏览器 `localStorage` 中。它适合确认产品流程和展示界面，但不同电脑或手机之间还不会同步。

正式投入使用前，需要接入在线数据库和用户身份验证。预约冲突必须由数据库唯一约束或事务处理，不能只依赖前端按钮状态。

## 本地查看

最简单的方式是直接双击 `index.html`。

也可以在项目目录启动任意静态文件服务器，例如：

```powershell
python -m http.server 8080
```

然后在浏览器打开 `http://localhost:8080`。

可以运行以下命令进行基础结构检查：

```powershell
node --check app.js
node tests/smoke-test.mjs
```

## 项目文件

```text
index.html   页面结构
styles.css   页面样式与响应式布局
app.js       预约、取消、封场和本地数据逻辑
```
